🌐 Monitor de Protocolos de Rede em Tempo Real (CLI)

Ferramenta de monitoramento de protocolos de rede em tempo real, desenvolvida em Python, que analisa conexões ativas diretamente a partir do sistema operacional.
O script fornece uma visão clara e contínua da atividade de rede, exibindo protocolos utilizados, categorias de serviço, IPs externos e processos associados, tudo em uma interface de terminal limpa, organizada e visualmente informativa.

✨ Principais Funcionalidades

Monitoramento em tempo real de conexões ativas (ESTABLISHED)

Identificação automática de protocolos de rede (HTTP, HTTPS, SSH, DNS, etc.)

Classificação inteligente por tipo de serviço:

WEB

EMAIL

BANCO DE DADOS

ACESSO REMOTO

REDE

Detecção dos IPs externos mais ativos

Associação das conexões aos processos do sistema

Interface CLI dinâmica com:

Cores ANSI

Barras gráficas de atividade

Indicadores visuais com emojis

Atualização automática (intervalo padrão: 3 segundos)

Encerramento seguro com Ctrl + C
